# 3D models

- `OLED_SSD1306_0.96in_I2C_24.8x26.9mm.step`: simplified model of the 0.96" OLED module,
  generated by `oled_model.py` (CadQuery). Same license as the rest of the hardware.
- `Waveshare_ESP32-S3-Zero.step`: 3D model of the Waveshare ESP32-S3-Zero module, published by
  Waveshare on the [ESP32-S3-Zero wiki](https://www.waveshare.com/wiki/ESP32-S3-Zero) and
  redistributed here for convenience. It remains Waveshare's property and is not covered by the
  PlancH licenses.
